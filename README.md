# Tetris Qt6

Классическая игра «Тетрис», реализованная на C++17 и Qt 6 с применением принципов чистой архитектуры. Проект создан в результате полного рефакторинга исходной версии: логика отделена от представления, используются современные возможности Qt и стандартной библиотеки.

## Возможности

- Игровое поле 10×15 (настраивается через константы).
- Семь стандартных фигур (I, O, T, S, Z, J, L) с поворотами.
- Отображение следующей фигуры.
- Система очков: 1 линия — 1 очко, 2 — 3, 3 — 5, 4 — 8 (классическая прогрессия).
- Уровни сложности (1–10). Скорость падения увеличивается с ростом уровня.
- Пауза (кнопка или клавиша `P`).
- Экран Game Over с градиентной заливкой и итоговым счётом.
- Поддержка пользовательского шрифта и иконки через ресурсы Qt.
- Полное разделение игрового ядра и пользовательского интерфейса.
- Отсутствие утечек памяти (используются умные указатели и родительские объекты Qt).

## Управление

| Клавиша      | Действие                     |
|--------------|------------------------------|
| `←`          | Сдвинуть фигуру влево        |
| `→`          | Сдвинуть фигуру вправо       |
| `↑`          | Повернуть фигуру             |
| `↓`          | Ускорить падение (один шаг)  |
| `Space`      | Мгновенно сбросить фигуру    |
| `P`          | Пауза / возобновление        |
| Кнопка Pause | Пауза / возобновление        |
| Кнопка Restart | Начать игру заново         |

## Требования

- **CMake** 3.19 или выше
- **Qt** 6.5 или выше (модули: Core, Widgets)
- Компилятор с поддержкой **C++17**
- Операционная система: Windows, Linux, macOS (теоретически любая, поддерживаемая Qt)
